# **App Name**: Brand Advocate Hub

## Core Features:

- Role-Based Access: User authentication with three distinct roles: Influencer, Company Admin, and Master Admin.
- Gamified Engagement: Influencers can complete learning paths, participate in missions, view leaderboards, and redeem rewards.
- Company Management: Company Admins can manage content, users, learning paths and rewards for their specific company.
- Platform Administration: Master Admins can manage client companies and global platform content.
- Brand Asset Library: Admins upload and manage brand assets for users to share.
- AI Content Refinement: AI content assistant tool refines user-generated text to align with the company's brand and messaging.
- Multilingual Support: Dual language support for Brazilian Portuguese and English.

## Style Guidelines:

- Primary color: Saturated blue (#468BFF) for professionalism and trustworthiness.
- Background color: Light, desaturated blue (#D7E2F7) for a clean backdrop.
- Accent color: Vibrant violet (#B75BFF) for CTAs and interactive elements.
- Sidebar color: Dark background (#2A1A48) with light text and the accent color for contrast and elegance.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-forward aesthetic.
- Body font: 'PT Sans' (sans-serif) for clear readability.
- Consistent use of icons from ShadCN/UI to represent key features.
- Employ a modern, component-based layout using ShadCN/UI, with rounded corners, subtle shadows, and clear visual hierarchy.
- Use subtle animations to enhance user interactions and provide feedback.
